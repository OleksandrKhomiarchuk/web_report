Report of Monaco 2018 Racing 🏁 🏎

This web application is designed to generate a report on the Formula 1 race held in Monaco in 2018.

## Technologies used

| Component                | Description                                                              |
|--------------------------|--------------------------------------------------------------------------|
| **Python 3**             | Main programming language                                                |
| **Flask**                | A lightweight web framework for routing, templating and server startup   |
| **Jinja2**               | HTML templating engine built into Flask                                  |
| **Bootstrap**            | CSS framework for responsive and modern UI                               |
| **JavaScript**           | Used for client-side interactivity                                       |
| **flasgger**             | Automatic documentation for Flask                                        |
| **peewee**               | A lightweight Python ORM for databases                                   |
| **pytest**               | Pytest – a powerful, concise Python testing framework                    |
| **f1_report_by_viacent** | Program for generating report for Formula 1 race - Monaco 2018           |

## Web application features


- View results of the 2018 Monaco Grand Prix
- Visualize driver tables, laps and times
- Clean and intuitive interface
- Easy to deploy and use
